# 极简测试 · 亡灵收藏家（网页试玩版）

五层 Roguelike 爬塔卡牌原型的网页构建产物，由 Godot 4.7.2 官方 Web 导出生成。

## 直接玩

部署到 GitHub Pages 后，打开：

```
https://<你的用户名>.github.io/<仓库名>/
```

首次打开需要下载约 57 MB 游戏数据，加载页会显示进度百分比。

## 关于这个仓库

- 这里**只有网页构建产物**，不含 Godot 工程源码。
- 采用**单线程**网页模板，**不需要 COOP/COEP 响应头**，因此 GitHub Pages 这种无法自定义响应头的托管也能直接运行。
- 进度自动保存在**玩家自己浏览器**里（IndexedDB）。关掉页面再打开，主界面「继续远征」可以接着打。
- 换浏览器或使用无痕模式 = 从头开始。

## 注意：不能下载后双击打开

浏览器在 `file://` 协议下不允许读取同目录的 `index.wasm` / `index.pck`，
所以**下载本仓库后双击 `index.html` 只会白屏**。必须通过 HTTP(S) 访问，也就是上面那个网址。

## 目录

| 文件 | 说明 |
|---|---|
| `index.html` | 页面外壳与中文加载页 |
| `index.js` | Godot 网页运行时胶水层 |
| `index.wasm` | 引擎（37.7 MB） |
| `index.pck` | 游戏数据与资源（19.5 MB） |
| `.nojekyll` | 关闭 GitHub Pages 的 Jekyll 处理 |
